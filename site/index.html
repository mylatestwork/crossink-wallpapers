From ZIP to reader

Four steps. No tools.

Each download already contains the correctly named .sleep folder for the root of your SD card.

  1. 01

    Choose a mode

    Download either the Custom ZIP or the Page Overlay ZIP.

  2. 02

    Extract the ZIP

    Inside is one ready-to-copy .sleep directory.

  3. 03

    Copy to SD

    Place .sleep in the root of the reader’s SD card.

  4. 04

    Select in CrossInk

    Open Settings → Display → Sleep Screen and choose the matching mode.

!

Compatibility works one way. Custom BMPs can also be used in Page Overlay mode, but transparent Overlay PNGs do not work in Custom mode. Both modes use the same folder, so do not merge the two ZIPs.

Source & credits

Built at the device’s native size.

The repository preserves the 480 × 800 Custom PNG masters. Custom sleep screens are flattened onto white and exported as uncompressed 24-bit BMP files; Page Overlays remain transparent PNG files.

Shapes are adapted from Shapes, Symbols & Icons - Vol. 1 and Vol. 2 by Counterfeit, licensed under CC BY 4.0. Selected shapes were resized, recolored, and converted into monochrome 480 × 800 CrossInk assets.
